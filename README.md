O principal objetivo é solidificar a base teórica e prática em Java, dominando os quatro pilares da POO:
* **Abstração:** Modelagem de cenários reais em classes e interfaces.
* **Encapsulamento:** Proteção de dados e controle de acesso aos membros de uma classe.
* **Herança:** Criação de estruturas hierárquicas para reutilização de código.
* **Polimorfismo:** Implementação de comportamentos flexíveis e adaptáveis.
