# Respostas - Lista de Exercícios 1

## Sobre

Este documento reúne as respostas da **Lista de Exercícios 1** da disciplina de **Linguagem de Programação II**, organizadas em formato Markdown para facilitar a leitura e consulta.

---

# 1) O que é um paradigma de programação?

**Resposta:**

É uma espécie de molde que contém um conjunto de regras estruturadas que organizam o código e a lógica.

---

# 2) Cite os principais paradigmas de programação.

**Resposta:**

* Imperativo
* Declarativo

---

# 3) O que é programação orientada a objetos? E quais suas vantagens?

**Resposta:**

É um paradigma de programação que tem como base a distribuição de atributos em classes e objetos, no qual cada um opera uma função separada sem necessariamente depender do outro, podendo serem chamados para realizar métodos específicos em classes específicas.

---

# 4) O que é abstração?

**Resposta:**

É organizar e focar nos aspectos essenciais para criar um algoritmo.

---

# 5) O que é uma classe?

**Resposta:**

A classe é um conceito da programação orientada a objetos que contém métodos que podem representar ações, características, comportamentos ou dados.
